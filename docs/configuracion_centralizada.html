Descripción

Modifique valores únicamente en config.yaml. El módulo Python declara los tipos, las propiedades derivadas y las validaciones. No mantiene otra copia de los valores.

Dónde ingresar columnas

Edite solo config.yaml.

  • entradas: ruta_dataset, columna_id, columna_tiempo, columna_target y listas manuales (columnas_conservadas, columnas_excluidas).

Auditoría final

Tres iteraciones y correcciones matemáticas. El esquema de ConfigPipeline coincide con todas las claves del YAML central.

Vigencia

Revisado el 2026-10-04. Fuente de valores: config.yaml. Validación: py -m pytest -q, 38 pruebas aprobadas. Los detalles de implementación y su historial se mantienen en los módulos Python.

Comportamiento

ConfigPipeline() y cargar_config() leen la misma fuente central. Cada instancia recibe listas independientes. Se rechazan archivos ausentes, raíces inválidas, claves repetidas entre secciones y parámetros obligatorios ausentes del YAML central. Logging y bootstrap respetan ruta_log, nivel_log, usar_boruta y autoinstalar_dependencias.

Alcance

Configure los valores en YAML. El módulo Python conserva tipos y validaciones. columnas_conservadas se transporta al final sin analizar; columnas_excluidas se retira antes del análisis y no se exporta. Vea la guía de columnas manuales.

Uso

Ejecute py run_pipeline.py. Para otra corrida use --config otro.yaml, que puede ser parcial. Precedencia: YAML central → YAML alternativo → flags. La ruta central se resuelve desde el proyecto; las rutas de datos y salidas se conservan relativas al directorio de ejecución.

PyYAML es requisito previo: py -m pip install PyYAML. Así puede leerse autoinstalar_dependencias antes de instalar cualquier otra librería. --sin-autoinstall prevalece sobre el YAML.

Validación: py -m pytest -q, con pruebas de lectura central, precedencia, aliases, independencia de listas, errores de configuración y arranque con bootstrap/pipeline simulados, además de las pruebas existentes de causalidad temporal.
