Conservación de exclusiones manuales

Feature Selection · 2026-10-02

Flujo

flowchart TD A[Dataset de entrada] --> X[Retirar columnas_excluidas] X --> B[Tipificar candidatas y roles] B --> C[Seleccion estadistica de candidatas] C --> D{Exportacion activa} D -->|No| E[Omitir archivo] D -->|Si| F{Seleccionadas o manuales presentes} F -->|No| E F -->|Si| G[Roles primero] G --> H[Seleccionadas] H --> I[Manuales al final sin duplicados] I --> J[Exportar CSV o Parquet]

Descripción

Dos listas contiguas en config.yaml: columnas_conservadas para conservar sin analizar; columnas_excluidas para no analizar ni exportar. Una columna no puede estar en ambas listas.

columnas_conservadas significa excluir de la evaluación. Las columnas presentes se conservan al final del dataset exportado, en el orden de la lista configurada.

Vigencia

Revisado el 2026-10-02. Fuente de valores: config.yaml. Validación: py -m pytest -q, 58 pruebas aprobadas. Los detalles de implementación y su historial se mantienen en los módulos Python.

Comportamiento

La exportación agrega columnas manuales existentes sin duplicarlas y funciona aunque no queden candidatas seleccionadas. La tipificación no convierte las columnas manuales, conservando códigos con ceros iniciales y otros valores. Se mantiene la advertencia de validación para nombres inexistentes.

Alcance

Roles → seleccionadas → manuales. Las manuales se transportan para uso posterior y no se cuentan como variables seleccionadas. Las descartadas por criterios estadísticos siguen fuera del dataset. La matriz especializada IF/VAE sigue usando las variables seleccionadas.

Uso

Configure entradas.columnas_conservadas y entradas.columnas_excluidas en config.yaml y ejecute el pipeline normalmente. El cambio aplica a nuevas exportaciones.

Validación: py -m pytest -q: 58 pruebas aprobadas, incluyendo CSV/Parquet, con/sin target, con/sin candidatas, valores conservados, columnas inexistentes y exportación desactivada.
