Descripción

Se prepara el puesto antes del diagnóstico. Con ambas fuentes se elige despuestocolaborador; con una, se usa esa. El nombre final es despuestocolaboradoragrupado. Se conserva en CSV/Parquet y se usa como contexto KDE cuando FE está activo.

    Otros aliases conocidos incluyen subgerente, jefe, supervisor, coordinador, auxiliar, técnico, ejecutivo y practicante. Calificadores reconocidos: adjunto, junior y senior. Las reglas son léxicas y no aprenden de datos futuros.

    Contexto y fallbacks

    La fuente elegida y el agrupado son conservadas, no candidatas; la fuente sobrante se retira. El grupo sustituye las fuentes dentro de context_vars y se agrega si no estaban configuradas. Otros contextos permanecen; job_position se retira únicamente si es un placeholder inexistente. Se usa una copia de cfg y no se reescribe el YAML.

    Sin fuente o con la preparación desactivada se mantiene el flujo normal. Textos irreversiblemente dañados no se reconstruyen con certeza; se usan las letras disponibles y las reglas simples. Valores vacíos reciben la etiqueta configurada. CSV prueba encodings alternativos solo ante UnicodeDecodeError y registra el elegido. Otros errores y configuraciones inválidas mantienen sus validaciones.

    Uso y verificación

    Configure puestos_colaborador en config.yaml. El interruptor de preparación está activo por defecto. Para KDE active usar_feature_engineering y configure behavior_vars numéricas reales, además de los otros contextos que quiera conservar. La preparación no activa FE ni reemplaza conductas inexistentes. Historia insuficiente mantiene features KDE nulas según las reglas existentes.

    Validación: 58 pruebas aprobadas con py -m pytest -q. Incluye dos pipelines completos sobre un panel sintético pequeño (con/sin target), exportación del agrupado, prioridad de fuente, aliases, mojibake, encoding CSV y causalidad KDE. No es una corrida contra datos reales del usuario.
